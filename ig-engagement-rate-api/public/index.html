IG Engagement Rate

Made by Desearch · Get an API key · View the code

Estimate engagement from up to 12 recent public posts. No captions, tagged users or images are displayed.


Rate = average (likes + comments) per eligible post / followers × 100. Hidden likes, posts under 24 hours old and pinned posts are excluded. Pinned flags are used when present; otherwise the first 3 posts are skipped. No eligible posts means n/a.
