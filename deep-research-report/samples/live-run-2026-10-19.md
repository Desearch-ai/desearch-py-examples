After deduping by link and near-identical title, the 100 results became 54 unique pages, and the report quotes 15 sentences from 15 different pages (3 per sub-question). Each quote was checked to be an exact part of the page text Desearch returned.

The public sample (`sample-raw.json`) keeps only the quoted sentence as page text for each page and leaves out pages whose title, passage or quote contains an account handle or banned words, so it rebuilds a smaller report (`sample-report.md`, `sample-sources.csv`).

Rebuild offline from the sample, no key and no cost:

```bash
python deep_research_report.py --from-raw samples/sample-raw.json --out output/sample
```
